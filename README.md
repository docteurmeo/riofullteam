# riofullteam

An interactive HTML demo built from a Figma layout: circles drop onto an arm-ramp
(Vector 1), roll down with real rolling physics, then arc into a basket (Vector 2)
where they collide and settle naturally. A fourth circle drifts around the viewport
as a fading "ghost". Includes the RIO / Sustainable Branding scene and logo.

## Run

Open `index.html` in any modern browser — no build step, no dependencies.

## Structure

- `index.html` — scene, physics simulation, and animation loop
- `assets/scene.png` — composited Figma frame (background, images, logo)
- `assets/circle1–3.png` — the rolling circles
- `assets/circle4.png` — the floating ghost circle
